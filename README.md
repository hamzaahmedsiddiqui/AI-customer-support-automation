# AI Customer Support Automation

AI-powered customer support automation platform built using:

- n8n
- OpenAI
- Zendesk
- Docker

## Features

- Ticket classification
- Priority detection
- Sentiment analysis
- AI-generated response drafts
- Automated routing

## Architecture

```text
Zendesk
    ↓
n8n
    ↓
OpenAI
    ↓
Ticket Analysis
    ↓
Zendesk
```
